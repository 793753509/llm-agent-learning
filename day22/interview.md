# 自测：把一句定义接到一段代码

参考答法由课程作者整理；证据列指向相应课程和代码。先运行实验，再按自己的实现回答。

先遮住“参考答法”列，用自己的话回答。回答到代码与边界即可，不用背原句。

| 问题 | 参考答法 | 可打开的证据 |
|---|---|---|
| RAG 在做什么？ | 先找外部证据，放进本次输入，再生成；资料没进入输入模型就看不到 | Day 05 build_prompt |
| 向量库一定在模型服务器吗？ | 不一定；本课程向量搜索在本地，生成可连接远程服务，两者独立 | Day 06 vector_store |
| Embedding 是答案吗？ | 是文本的数值表示，用来比较/检索，不是自然语言答案 | Day 06 |
| 为什么先建关键词基线？ | 简单可观察，可作为同题比较对象；同义表达可能漏检 | Day 05/08 |
| 为什么过滤要早做？ | 两路只接触获准/指定范围，避免一条路线带入不该读的资料 | Day 07 |
| RRF 解决什么？ | 合并不同检索器的排名，不直接混加不可比的原始分数 | Day 07 fusion |
| 规则重排是神经网络吗？ | 不是；本例仅按完整错误码匹配优先，范围很窄 | Day 07 reranker |
| Hit 和 Recall 有何区别？ | 至少一条命中与正确资料找全比例不同，多证据题可区分 | Day 08 metrics |
| MRR 怎样算？ | 每题取第一条正确结果排名的倒数，再平均，注明截断 k | Day 08 |
| 引用存在就一定正确吗？ | 不一定，存在性、支持结论、完整性要分别核对 | Day 08/17 |
| 如何判断错误在检索还是生成？ | 按实际候选、选中上下文、最终回答逐层检查 | Day 08 |
| Agent Loop 是什么？ | 获取决策，校验并执行工具，把结果送回，再决定结束或继续 | Day 02/04 |
| 工具 call_id 有何用？ | 把工具结果对应到提出它的那次请求，避免多次调用结果串线 | Day 02/04 |
| 工具调用与结构化回答有什么区别？ | 一个提出执行动作，一个约束最终数据形状；返回 JSON 不代表已执行工具 | Day 02/04 |
| LangChain 与 LangGraph 有何区别？ | 前者提供模型接口和现成 Agent 循环，后者直接控制状态与流程；LangChain Agent 底层使用 LangGraph | Day 09/10 |
| create_agent 替你做了什么？ | 组织模型调用、工具执行和结果回传；工具业务、权限和效果评估仍由应用负责 | Day 09 |
| State/Node/Edge 是什么？ | 当前共享数据、做事函数、下一步路线 | Day 10 |
| Reducer 为何会导致重复日志？ | 节点若回传全历史，拼接 reducer 会再加一次；只回本次新增 | Day 10 |
| compile 会请求模型吗？ | 不会，它准备图；invoke 才执行节点，节点是否调用模型由代码决定 | Day 10 |
| 如何结束工具循环？ | 明确结束条件，再加步数/调用/时间预算；不能只靠 Prompt | Day 10 |
| Session 和 checkpoint 不同在哪？ | 会话关联多轮；checkpoint 保存流程状态及恢复位置 | Day 11/13 |
| interrupt 恢复从哪继续？ | 暂停节点从头重跑，interrupt 在恢复时取得输入，前面的副作用要避免重复 | Day 11 |
| 审批和幂等能互相代替吗？ | 不能；审批确认获准内容，幂等防止相同动作重放产生重复效果 | Day 11 |
| 内容摘要能当权限凭证吗？ | 不能；它绑定文字，不能证明谁有权批准 | Day 11 |
| MCP 和 Function Calling 有何关系？ | MCP 连接应用与工具服务；模型工具调用给出建议，应用可以通过 MCP 执行 | Day 12 |
| 工具/资源/模板怎么区分？ | 带参数的动作、按 URI 读取内容、可复用提示模板；工具也能只读 | Day 12 |
| SQLite 记忆会改模型权重吗？ | 不会；应用显式读取后放进输入，或用它控制本地逻辑 | Day 13/20 |
| 如何离线评估 Agent？ | 固定输入/执行替身，检查真实执行层轨迹与答案；注明不是模型能力测试 | Day 14 |
| trace 和 span 什么关系？ | 一个请求编号串起若干步骤编号，分别记录开始/结束/错误 | Day 15 |
| usage 缺失能算 0 吗？ | 不能，未知是 None；计费还要核对单位和已包含的 token，避免重复算 | Day 15 |
| Prompt 能充当权限系统吗？ | 不能；执行层仍需工具允许列表、参数校验和资源权限检查 | Day 16 |
| 多 Agent 什么时候值得？ | 分工或独立核对带来可验证收益时；否则额外调用会增加等待与成本 | Day 17 |
| SSE 是否等于逐 token？ | 不等于，本例发阶段事件；逐 token 还需要读取模型的增量流 | Day 18 |
| 同会话锁能跨 worker 吗？ | 本例不能，锁和字典属于当前进程；多个进程需共享存储/协调 | Day 18 |
| 本地验收全部通过说明什么？ | 这组固定集成检查通过；不等于同样数量的独立模型题或生产保证 | Day 21 |
| 作品三个限制是什么？ | 固定身份、规则路由、未评估真实模型回答；还可指出读写工单未统一 | capstone/README |
