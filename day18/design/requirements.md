# 青禾自习室助手：最小需求

使用者：北店值班人员；本地演示身份 alice。资料和工单全部虚构。

| 编号 | 输入或动作 | 可观察结果 |
|---|---|---|
| K1 | E101 预约失败怎么办？ | 北店 E101 原文首位，并附来源 |
| T1 | 查工单 T001 | 经 MCP 读取自己的工单，显示处理中 |
| T2 | 查工单 T002 | 拒绝，不出现 bob 的正文 |
| C1 | 计算 25 * 3 | 有限乘法工具返回 75 |
| W1 | CLI draft | 草稿持久化，状态 waiting_approval |
| W2 | 对同一 ID approve 两次 | 状态完成，模拟表只有一条 |
| W3 | 对新草稿 reject | 状态 rejected，不写入 |
| M1 | remember 简短 | 后续知识预览最多一段；可 forget |
| A1 | POST /chat | JSON 包含来源、请求编号、会话计数 |
| A2 | POST /events | status → answer → done；失败为 error |

默认只做候选资料预览。向量检索和远程生成通过独立 CLI 开关启用。
不含真实登录、公网部署、自动多步规划、完整对话记忆、逐 token 流或外部写入。
验收不使用真实客户资料，不宣称生产准确率或生产容量。
